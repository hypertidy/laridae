# laridae: constrained triangulation and meshing with CGAL

A persistent constrained Delaunay triangulation handle backed by CGAL.
See
[`lari_new()`](https://hypertidy.github.io/laridae/reference/lari_new.md)
for the handle API and
[`lari_triangulate()`](https://hypertidy.github.io/laridae/reference/lari_triangulate.md)
for the one-shot form.
